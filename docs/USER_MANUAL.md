## 1. 快速开始

### 1.1 安装与启动

```bash
# 1. 克隆项目
git clone https://github.com/Eternity-TJ/artic-workbench.git
cd artic-workbench

# 2. 安装依赖
npm install

# 3. 启动开发服务器
npm run dev
```

打开浏览器访问 **http://localhost:3000**。

### 1.2 获取 API Key

Artic 使用 **DeepSeek API Key** 进行认证。请先到 [platform.deepseek.com](https://platform.deepseek.com) 注册并获取你的 API Key（格式为 `sk-` 开头）。

### 1.3 首次登录

1. 访问首页 `http://localhost:3000`
2. 点击 **「进入工作台」** 按钮
3. 在弹出的对话框中输入你的 DeepSeek API Key
4. 系统会自动验证 Key 的有效性
5. 验证通过后进入 Dashboard

> 💡 Key 仅保存在你当前浏览器的本地存储中，不会上传到任何服务器。更换浏览器或清除浏览器数据后需重新输入。

### 1.4 重新验证

如需更换 Key 或重新验证：

- **方法一**: 访问 `http://localhost:3000/reset.html` 自动清除
- **方法二**: 进入 Dashboard → 设置 → API Key 卡片 → 点「清除 Key」或「更换 Key」
- **方法三**: 浏览器控制台执行 `localStorage.removeItem("artic-api-key")`

## 2. 认证与安全

### 2.1 验证流程

```
用户输入 Key → 调用 DeepSeek API 验证 → 通过则保存到 localStorage → 进入工作台
                                              ↓ 失败
                                         显示错误提示，拒绝进入
```

### 2.2 安全特性

| 特性 | 说明 |
|---|---|
| 本地存储 | Key 仅保存在浏览器 localStorage，不上传任何服务器 |
| 每次验证 | Dashboard 每次加载时验证 Key 有效性 |
| 网络容错 | 网络不通时允许使用已保存的 Key（不误拦） |
| 独立 Key | 每位用户使用自己的 Key，消耗各自配额 |

## 8. 数据比对

三 Tab 数据工作台：文件导入 + 数据对比 + A/B 测试。

### 8.1 导入数据（Tab 1）

**支持格式**：CSV、XLSX、XLS、DOCX

**操作步骤**：
1. 拖拽文件到上传区，或点击选择文件
2. 系统自动解析并预览前 50 行
3. 命名数据集并保存

**快速体验**：点击「下载示例 CSV」获取 A/B 测试示例数据。

### 8.2 数据对比（Tab 2）

1. 从已导入的数据集中选择 2 个
2. 系统自动匹配公共列名
3. 并排对比：数值列显示差异值(Δ)，文本列高亮不同行
4. 可导出对比结果为 CSV

### 8.3 A/B 测试（Tab 3）

**真实统计检验**（纯 TypeScript 实现）：
- z-test（两样本比例检验）
- Chi-square（卡方检验）
- p-value 计算
- 95% 置信区间
- Cohen's h 效应量

**操作**：导入含 `variant`、`impressions`、`clicks`、`conversions` 列的 CSV，系统自动分组计算并输出统计结论。

**手动模式**：也可手动输入 A/B 两组数据直接计算。

## 14. 常见问题

### Q: 为什么我输入 API Key 后提示无效？

A: 请确认：
1. Key 是从 [platform.deepseek.com](https://platform.deepseek.com) 获取的
2. Key 格式为 `sk-` 开头
3. 网络可以访问 `api.deepseek.com`
4. Key 未过期或余额充足

### Q: 更换电脑后需要重新输入 Key 吗？

A: 是的。Key 保存在浏览器本地，换电脑或换浏览器需要重新输入。

### Q: 数据会丢失吗？

A: 所有数据存储在浏览器的 localStorage 中。清除浏览器数据会导致数据丢失。建议定期导出重要数据。

### Q: 支持多人协作吗？

A: 当前版本为单机版，每位用户的数据独立存储在自己浏览器中。如需团队协作，可以考虑将数据导出分享。

### Q: 如何导出数据？

A: 数据比对模块支持导出对比结果为 CSV。其他模块的数据可通过浏览器控制台 `JSON.parse(localStorage.getItem("键名"))` 获取。

### Q: 侧边栏怎么调回来？

A: 拖到太小的话，鼠标移到左侧边缘找到分隔线，向右拖回即可。最小 180px，不会完全消失。

### Q: 日历里活动显示不全？

A: 每个日期格最多显示 2 个活动和 2 个内容标签。点击日期格可在右侧面板查看完整的当日列表。
